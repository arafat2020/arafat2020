## Selected projects

### [Sentinel](https://github.com/arafat2020/sentinel)
Host-based telemetry and behavioral detection agent for Linux, macOS, and Windows. Collects process, network, DNS, and file events (including eBPF on Linux), correlates them through an in-process event bus, and surfaces findings in a local TUI — no external services required.

`Go` · `eBPF` · `SQLite` · `TUI`

### [VCon](https://github.com/arafat2020/v-con)
Rust CLI/TUI for managing SSH host inventories. Browse hosts, jump sessions, run commands across a fleet, watch health, move files over SFTP, and keep tunnels in one place — driven by system OpenSSH rather than reinventing auth.

`Rust` · `SSH` · `TUI` · `TOML`

### [AuroraDbManager](https://github.com/arafat2020/aurora-db-manager)
.NET platform for provisioning and managing database instances through Docker. Focused on instance lifecycle, backup/restore workflows, and the operational glue around database infrastructure.

`C#` · `.NET` · `Docker`

### [Kurenai](https://github.com/arafat2020/kurenai)
A small DSL and compiler for FFmpeg. Describe video and audio pipelines in readable syntax; Kurenai handles parsing, validation, and command generation — including WebCodecs targets for in-browser processing.

`TypeScript` · `FFmpeg` · `DSL` · `WebCodecs`

### [Worker Management System](https://github.com/arafat2020/worker_management)
Backend for a mobile worker management app — auth, real-time updates, background jobs, and push notifications.

`NestJS` · `PostgreSQL` · `Prisma` · `Redis` · `BullMQ` · `WebSockets` · `Firebase`
